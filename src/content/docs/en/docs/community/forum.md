The ZIGNOS user forum runs on **GitHub Discussions**.
Use it for questions, troubleshooting, feature requests and showing off your setup.
Report bugs in Issues.

- [Open the forum](https://github.com/studio-nosa-tech/zignos/discussions)
- [Issues (bug reports)](https://github.com/studio-nosa-tech/zignos/issues)

Reading does not require an account; posting and replying need a GitHub account.

## Categories

The category names on GitHub are English.

| Category | Use |
|---|---|
| [Announcements](https://github.com/studio-nosa-tech/zignos/discussions/categories/announcements) | Releases and maintenance notices |
| [Q&A](https://github.com/studio-nosa-tech/zignos/discussions/categories/q-a) | Installation, boot, Plasma, Japanese input and other questions |
| [Ideas](https://github.com/studio-nosa-tech/zignos/discussions/categories/ideas) | Feature requests and improvements |
| [Show and tell](https://github.com/studio-nosa-tech/zignos/discussions/categories/show-and-tell) | Screenshots and setup stories |
| [General](https://github.com/studio-nosa-tech/zignos/discussions/categories/general) | Off-topic chat |
| [Polls](https://github.com/studio-nosa-tech/zignos/discussions/categories/polls) | Community polls |

Start with **Q&A** for questions. Once answered, mark the most helpful reply as
the answer so people searching for the same problem can find it.

## What to include

- Channel (stable / testing / unstable) and `zpkg --version`
- `uname -r`
- The command you ran and the full error output (do not truncate it)
- For builds: the recipe name and the log in `/var/cache/zpkg/logs/...`
- For VMs: QEMU / VMware / VirtualBox, firmware (BIOS / UEFI), and GPU (`-vga` type)
- For desktops: session (Wayland / X11), GPU and `VIDEO_CARDS`

## Rules

- Search first; add to an existing thread instead of opening a duplicate
- Do not post personal information (IP addresses, SSH keys, passwords, license keys)
- Abusive language, advertising and unrelated topics may be removed

Report bugs in [Issues](https://github.com/studio-nosa-tech/zignos/issues).
Use the forum for questions, advice, requests and sharing.
