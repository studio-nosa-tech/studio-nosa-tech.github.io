## ルートファイルシステムは何を使いますか?

現行のインストールガイドは **ext4** を前提にしています。stage3 を展開して
chroot する手動インストールなので、カーネルとツールが対応していれば別の
ファイルシステムも技術的には選べますが、公式手順と検証は ext4 が対象です。

## ESP は必要ですか?

UEFI で起動する場合は必要です。**FAT32** でフォーマットし、通常 512 MiB
(最低 300 MiB、複数カーネルを置くなら 1 GiB 程度)を目安にします。
BIOS の場合は ESP は不要で、MBR のディスクに GRUB を入れます。

## スワップは必要ですか?

必須ではありません。メモリが少ない場合やハイバネートを使う場合に用意します。
スワップあり・なしの両方のレイアウトを [インストールガイド](/docs/install/) に
記載しています。

## fstab はどう書きますか?

UUID を使います。`blkid` で root / ESP / swap の UUID を確認し、
`/etc/fstab` に記述してください。stage3 には `zignos-fstab` が同梱されており、
マウント済みの root から雛形を生成できます。誤った UUID を書くと `/` が
read-only で起動するため、初回起動前に確認してください。

## LUKS や TPM は使えますか?

現時点では**未対応**です。公式のインストール手順は暗号化なしを前提にしています。
LUKS / TPM の自動セットアップは今後の課題です。

## LVM / XFS / Btrfs は使えますか?

現行の公式ガイドと検証は ext4 が対象です。LVM や XFS / Btrfs は手動構築の
範囲になります。stage3 の kernel 設定や必要なツールが揃っているかを確認し、
自己責任で構成してください。インストーラの自動検出・変換はありません。

## ディスクを消さずに試せますか?

QEMU の仮想ディスクを使うのが安全です。開発元の検証でも QEMU の BIOS / UEFI
起動を使っています。実ディスクへ書き込む前に、必ず対象ディスクを `lsblk` で
確認してください。
